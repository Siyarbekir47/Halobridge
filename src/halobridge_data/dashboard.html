How are the numbers captured?

Usage shows completed inference requests through this router. Token counts come exclusively from the API's usage object. Missing values show as “–”; partial sums are marked as incomplete. In-flight requests are only counted after completion.

Input includes cache tokens. Output includes reasoning tokens. These subsets are not added again. The cache ratio only considers requests that report both input and cache. “0” means an actually reported zero value.

Legacy records remain in the history but are not included in verified token totals due to earlier inconsistent capture. Engine logs with similar timing are never automatically matched to a request.

Duration spans from the start of forwarding to the end of the response. TTFB is the time to the first response byte, not the first token. TPS is only shown when a direct time measurement exists. Streaming aborts may remain without a final usage report.

Technical metadata is stored for 365 days. Prompts, responses, images, tool contents, and keys are not stored.

Install a model

Official downloads about 118 GiB on first start. Uncensored downloads the GGUF, converts it, then starts. Halobridge serves one backend at a time: installing pauses the currently active model and starts the new one afterwards. On failure it rolls back to the previous model automatically.
